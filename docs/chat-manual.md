# LoopV Chat 操作手册

> 适用于 chat.loopv.net 聊天室与 admin.loopv.net 管理平台

## 一、聊天室（chat.loopv.net）

### 1. 注册与登录

- 打开 **https://chat.loopv.net**
- 页面默认显示登录表单，可切换「注册」模式
- **注册**：填写用户名（2-20 字符）、密码（6-64 字符）、确认密码、昵称（选填，默认同用户名）
  - 需**两次输入密码**确认一致才能提交；密码框右侧眼睛按钮可切换明文/密文
  - 无需邮箱、手机号等私人信息验证
  - **第一个注册的用户自动成为管理员**，可访问管理平台
- **登录**：用户名 + 密码（可切换明文查看），登录后自动进入聊天室
- 登录状态保存在浏览器本地，刷新页面自动恢复；点右上角退出按钮登出

### 2. 发送消息

| 类型 | 操作 |
|---|---|
| **文本** | 输入框打字，Enter 发送，Shift+Enter 换行 |
| **表情包** | 点击输入框左侧 😀 按钮选 emoji；也可直接输入纯 emoji 字符（如 🎉），会以大字号显示 |
| **图片** | 点击 📎 按钮选择图片；**支持直接粘贴截图**、拖拽图片到输入框 |
| **视频** | 点击 📎 选择视频文件，发送后以内嵌播放器显示 |
| **音频** | 点击 📎 选择音频文件，发送后以播放条显示 |

- 上传前有预览，可点 ✕ 取消
- 每条消息显示：头像、昵称、发送时间、内容

### 3. 撤回消息

- **自己发送的消息**，时间后面有常显的「撤回」箭头图标（类似 return/回车键），低调不显眼
- 点击撤回，弹出**二次确认**弹窗（「确定要撤回这条消息吗？」），确认后执行
- 撤回不限时间，撤回后消息显示为「消息已撤回」
- 只有自己能撤回自己的消息（管理员可撤回任意消息）

### 4. 修改昵称与头像

- 点击顶栏 ⚙️ 设置按钮
- **更换头像**：仅支持图片，自动裁剪为圆形，可选可不选
- **修改昵称**：保存后立即生效，历史消息即时同步更新
- 无头像时显示昵称首字的彩色圆形底

### 5. 时区显示

- 消息时间默认按**北京时间（东八区）**显示，格式：`2026年09月01日 14:30`
- 点击 ⚙️ 设置 → 「时区」下拉可切换到其他 19 个常用时区（中文名 + 动态 UTC 偏移）
- 设置保存在浏览器本地，切换后已显示的消息时间即时刷新

### 6. 在线用户列表

- **桌面端**：右侧固定侧边栏，显示「在线成员 (N)」
- **移动端**：顶栏「在线 N」按钮，点击弹出面板
- 自己显示「（我）」标记；不显示任何角色 tag
- 用户连接/断开实时更新；顶栏刷新按钮可强制刷新在线成员

### 7. 通知与音效

点击 ⚙️ 设置，通知设置分为两组（均**默认关闭**，保存后生效）：

- **上下线提醒**
  - **消息提示**：开启后有用户上线/下线时，消息区顶部弹出毛玻璃胶囊提示（绿点=上线、灰点=下线），数秒后自动消失
  - **音效**：开启后上下线提示附带提示音（上线升调、下线降调）
- **新消息提醒**
  - **音效**：开启后他人发消息时播放清脆「叮」提示音，自己的消息不响

### 8. 连接状态与消息同步

- 顶栏刷新按钮**图标正中心**的小圆点表示连接状态：**绿色 = 已连接**，**红色 = 连接断开（自动重连）**，橙色 = 连接中
- WS 异常断开后自动重连，重连成功自动补齐断线期间错过的消息
- 顶栏刷新按钮（旋转箭头）可手动刷新：重新加载历史消息 + 强制刷新在线成员，点击时图标旋转

### 9. 注意事项

- 消息存储在 Cloudflare D1 数据库，持久化保存，关闭浏览器不丢失
- 图片/视频/音频存储在 R2，通过链接访问
- 账号被管理员封禁后无法登录
- 消息一经发出即对在线用户可见，撤回仅改变可见性、无法回收已送达内容；数据处理方式见[《LoopV 隐私政策》](privacy-policy.md)

## 二、管理平台（admin.loopv.net）

### 1. 登录

- 打开 **https://admin.loopv.net**
- 用**管理员账号**登录（聊天室第一个注册的用户）
- 非管理员账号登录会提示「无管理员权限」

### 2. 统计看板

- 登录后首页展示 4 个统计卡片：
  - 用户总数 / 消息总数 / 已撤回消息数 / 已删除消息数

### 3. 用户管理

#### 列表与筛选
- 顶部筛选栏：
  - **用户名**：模糊匹配
  - **昵称**：模糊匹配
  - **角色**：全部 / 管理员 / 普通用户 / 测试用户
  - **状态**：全部 / 正常 / 已封禁
  - 点「查询」应用筛选，「重置」清空

#### 封禁 / 解封
- 普通用户和测试用户行有「封禁/解封」按钮，二次确认后执行
- 被封禁用户的会话立即失效，无法再登录
- 管理员账号不能封禁

#### 创建测试用户
- 点顶部「创建测试用户」按钮
- 填写用户名 + 密码 + 昵称（选填）
- 创建成功后显示**明文密码**，可复制保存
- 测试用户权限与普通用户完全一致，仅多出「后台可查看密码」的能力

#### 删除用户
- 普通用户和测试用户行有「删除」按钮，二次确认后删除
- 管理员账号不能删除

### 4. 消息管理

#### 列表与筛选
- 顶部筛选栏：
  - **开始时间 / 结束时间**：日期时间范围
  - **发送者**：昵称模糊匹配
  - **状态**：全部 / 正常 / 用户撤回 / 管理员撤回 / 已删除
  - 点「查询」应用筛选，「重置」清空

#### 消息状态
| 状态 | 含义 | chat 界面显示 |
|---|---|---|
| 正常 | 消息正常 | 正常显示 |
| 用户撤回 | 发送者自己撤回 | 「消息已撤回」 |
| 管理员撤回 | 管理员在后台撤回 | 「已被管理员撤回」 |
| 已删除 | 管理员在后台删除 | **完全不显示** |

#### 撤回 / 删除
- **撤回**：正常消息可撤回，状态变为「管理员撤回」，chat 在线用户即时看到「已被管理员撤回」
- **删除**：正常/已撤回消息可删除，状态变为「已删除」，chat 界面完全移除该记录（含在线用户实时同步）

#### 批量删除
- 勾选消息前的复选框（已删除的消息不可勾选），顶部「批量删除」按钮
- 二次确认后一次性删除所有勾选消息

### 5. 注意事项

- 管理操作（撤回/删除/封禁）会实时广播，chat 在线用户即时感知
- 删除操作不可恢复
